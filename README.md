# Executive Performance Dashboard

## 📊 Project Overview

This project presents an **Executive Performance Dashboard** created using **Microsoft Power BI**.

The dashboard provides an interactive view of business performance and helps users analyze important sales and business metrics.

## 🛠️ Tools & Technologies

* Power BI
* CSV
* Data Cleaning
* Data Analysis
* Data Visualization

## 📈 Dashboard Features

* Executive-level performance overview
* Sales performance analysis
* Business performance KPIs
* Interactive charts and visualizations
* Category-wise analysis
* Trend analysis
* Interactive filtering

## 🎯 Objective

The objective of this project is to transform raw business data into an interactive Power BI dashboard that makes it easier to understand performance, identify trends, and support data-driven decision making.
